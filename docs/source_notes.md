# Source and Verification Notes

The product and pricing landscape changes frequently. The tool directory stores official product URLs, an indicative INR cost and a per-row verification note. Free, freemium and paid classifications are educational starting points, not purchase advice. Recheck the official product page, organisational approval, data terms and regional availability before a workshop or deployment.

INR figures were reviewed on 26 July 2026. Where a public international price was available, it was rounded using approximately ₹96.5 per US dollar. Taxes, card charges, purchasing channel, annual-billing conditions, institutional discounts and currency movements are excluded. `₹0` refers only to the stated free tier or software licence; hosting, implementation, support and governance can still create costs. Quote-based products are labelled rather than assigned false precision.

The application architecture follows Streamlit's current `st.Page` and `st.navigation` multipage model. Community Cloud deployment uses a repository, entrypoint file and dependency declaration.
