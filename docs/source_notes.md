# Source and Verification Notes

The product and pricing landscape changes frequently. The tool directory stores official product URLs and a per-row verification note. Free, freemium and paid classifications are educational starting points, not purchase advice. Recheck the official product page, organisational approval, data terms and regional availability before a workshop or deployment.

The application architecture follows Streamlit's current `st.Page` and `st.navigation` multipage model. Community Cloud deployment uses a repository, entrypoint file and dependency declaration.
