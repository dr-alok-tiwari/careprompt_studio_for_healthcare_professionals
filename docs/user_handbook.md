# User Handbook

1. Start with **Get Started** and select your role and objective.
2. Open the relevant studio and use fictional or de-identified context.
3. Select the audience, output format, detail level and safety nudges.
4. Review any identifier warning before generating the prompt.
5. Copy the prompt into an approved AI tool or save it to My Workspace.
6. Verify facts, sources, applicability and professional boundaries before use.

## CRAFT-MED
Context, Role, Audience, Format, Task, Medical safeguards, Evidence and Details.

## Escalation
High-risk outputs require clinical, pharmacovigilance, medical, legal, regulatory, statistical or research-integrity review, depending on the workflow.
